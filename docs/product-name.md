# Product Name

**Construction Weather Monitor**

## Notes

- The name is descriptive and is used as a working name, not a trademark claim.
- It appears in the UI header ("CONSTRUCTION WEATHER MONITOR") and the footer
  ("Construction Weather Monitor · Role-Based Secure Installation").
- The repository slug is `Weather-Monitor`.
- The package name is `construction-weather-monitor`.

## Alternatives considered (not adopted)

- "Site Weather Safety Enclave" — the in-app banner already uses "Safety
  Enclave" as a product-adjacent term for the authentication boundary.
- "Crane Weather Guard" — narrower than the actual scope, which covers all site
  activities, not only cranes.

If the name changes, update the UI strings, `README.md`, `package.json`,
`metadata.json` and this document together.
